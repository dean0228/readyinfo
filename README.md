# 即知 ReadyInfo

一款面向 AI 信息阅读场景的本地优先桌面应用，帮助用户把分散的信息源整理成可搜索、可追溯、可快速理解的阅读工作台。

> 当前为产品展示仓库。完整源代码与安装包暂未公开。

## 为什么做它

AI 行业信息密集、来源分散，真正重要的内容很容易被重复报道和信息噪声淹没。ReadyInfo 希望把“收集、筛选、阅读、理解、回查原文”整合成一条清晰的本地工作流。

## 核心能力

- 聚合 RSS、公开网页与 AI 信息源
- 按日期、来源和频道组织内容
- 使用 SQLite FTS5 搜索标题、摘要与正文
- 聚合重复报道并保留原文追溯入口
- 提供中文速览、翻译和文章问答
- 支持 OpenAI、DeepSeek、MiniMax 及兼容接口的 BYOK 配置
- 阅读记录、收藏和偏好默认保存在本机
- API Key 使用系统安全存储，不写入阅读数据库

## 产品原则

- **本地优先**：阅读数据与个人偏好优先留在用户设备中
- **来源可追溯**：保留来源、作者和原文入口，不让 AI 摘要成为信息终点
- **按需使用 AI**：未配置模型时仍可完成基础阅读、搜索和整理
- **安全边界明确**：外部网页内容按不可信输入处理，并限制网络访问范围
